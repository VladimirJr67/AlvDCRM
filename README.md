# Алвид CRM

Локальная CRM для работы с клиентами, задачами и заказами: один сервер на весь
офис, база — файл `db.json` рядом с сервером. Без сборки и внешних зависимостей.

## Быстрый запуск

1. Двойной клик по **`start.bat`** (либо в терминале: `node server.js`).
2. Браузер откроется сам: **http://localhost:3000**
3. Вход по умолчанию: `Admin` / `Admin` — администратор, `manager` / `manager` — менеджер.

Окно сервера закрывать нельзя, пока работаете в CRM. Остановить — `Ctrl+C`.

> `npm start` в PowerShell не сработает: политика выполнения скриптов блокирует
> `npm.ps1`. Используйте `start.bat` или `cmd /c npm start`.

## Как подключить коллег

Коллегам нужен адрес этого компьютера в локальной сети — например
`http://192.168.0.165:3000` (свой IP смотрится командой `ipconfig`).
Изменения сразу видны всем: данные лежат в общей базе `db.json`.

## Настройки, которые стоит сделать сразу

- **Должности пользователей** — Администрирование → Пользователи. Без них выбор
  соисполнителя покажет только ФИО.
- **Ключ Дадаты** — Администрирование → Интеграции: включает автозаполнение
  реквизитов по ИНН и точные подсказки городов. Ключ хранится на сервере в
  `config.local.json` и в git не попадает.
- **Справочники** типов организаций и должностей наполняются сами — из уже
  введённых карточек и из импортов, и сразу доступны всем менеджерам.

## Импорт клиентов

Раздел «Клиенты» → кнопки **«Шаблон»** (скачать файл с колонками и примером) и
**«Импорт»**. Колонки ищутся по названию с синонимами, поэтому порядок столбцов
в файле не важен. Поддерживаются `.xlsx`, `.xls` и `.csv`.

## Резервная копия

Вся база — один файл `db.json` в папке проекта: для бэкапа достаточно его
скопировать. Чтобы начать с чистой базы, остановите сервер, удалите `db.json` и
запустите снова — файл создастся заново с пользователями по умолчанию.

## Важно про безопасность

У сервера нет авторизации, и он слушает все сетевые интерфейсы: любой, кто знает
адрес, видит и может изменить всю базу, включая пароли пользователей — они
хранятся открытым текстом. Используйте CRM только в доверенной локальной сети и
не выставляйте порт 3000 в интернет.

## Из чего состоит проект

| Файл | Назначение |
|---|---|
| `server.js` | сервер: раздаёт статику, хранит базу, прокси к Дадате |
| `index.html`, `css/`, `js/` | одностраничное приложение (без сборки) |
| `db.json` | общая база: клиенты, контакты, задачи, заказы, справочники |
| `config.local.json` | локальные ключи интеграций (в git не попадает) |
| `js/lib/xlsx.full.min.js` | библиотека чтения и записи Excel |

## Проверка перед работой

Откройте CRM в двух окнах (обычное и режим инкогнито) под разными
пользователями — так видно, как работает общая база: изменения, уведомления и
раздел «Задачи» синхронизируются между окнами автоматически.
